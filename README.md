# Orbit Quest support site

Static, tracker-free Support / Privacy / Terms pages for the Orbit Quest iOS app, meant to be published as
its own **public** repository (`meraldemircioglu/orbit-quest-support`) on GitHub Pages, following the same pattern as
`hex-color-picker-support`. The app links to:

- https://meraldemircioglu.github.io/orbit-quest-support/ (support)
- https://meraldemircioglu.github.io/orbit-quest-support/privacy.html
- https://meraldemircioglu.github.io/orbit-quest-support/terms.html

Legal name, mailbox and retention period are copied from the Hex Color Picker site (Meral Demircioğlu,
mdappssupport@gmail.com, six months). Confirm them before publishing.
